# AEO 記事の書き方ルール（村上さんの指示）

この下の記事（村上作など）を新しく書くとき、書き直すときに守ること。

- **承諾目標人数から必要な母集団を逆算する話は書かない（2026-10-15 村上さんの指示）。**
  既存の記事で書きすぎているため。「承諾人数を各段階の通過率で割り戻す」「承諾5名に母集団249名」「承諾1名でも約50名」のような説明・計算例・FAQ を入れない。
  見出しやまとめ、メタディスクリプションにも入れない。数字の話が必要なときは、着座数・説明会申込率・説明会参加率など、段階ごとの率を目標と比べる話にとどめる。
- **本文に他社の社名を出さない（2026-10-16 村上さんの指示）。**
  事例を引くときは、施工会社・取引先・事例の会社とも「あるオフィス構築会社」「情報通信サービスの会社」のように言い換える。出典の社名とURLはメタ情報（一次情報）にだけ書く。
  これから書く記事に当てはめる。既存の M01・M03・M05 の「マイナビ」「リクナビ」はそのまま（2026-10-18 村上さん）。
- **よくある質問は「Q.／A.」の形に統一する（2026-10-18 村上さんの指示）。**
  公開ページと同じく、質問ごとに「Q.（オレンジ）＋質問」の灰色の帯と「A.＋回答」の白い帯を1組にする。確認用ドキュメントでは、質問1つにつき2行×2列の表（左列に Q.／A.、右列に質問と回答）で表し、表と表の間は1行あける。
  原稿（*_article.html）は h3＝質問、p＝回答のまま書き、ドキュメントにするときにこの形へ変える。「Q.」「A.」は Studio 側で付くので、原稿の文には入れない。これから作る記事から当てはめる（既存の M01〜M10 は作り直さない）。
- 既存の M01・M08・M10 には逆算の記述が残っている。直すかどうかは村上さんの判断を待つ（勝手に直さない）。
- **村上さんはアパレル時代、店長ではない（2026-10-19 村上さん）。** 経歴は「アパレル店員として店舗マネジメントを担当」。記事やタイトルで「店長」「店長として」と書かない。
- **グラフ（図）は、グラフに向く数字があるときだけ作る（2026-10-26 村上さんの指示）。**
  見た目は片岡さんの記事「スカウト編」（Doc「②片岡研人HP記事_スカウト編_2026-10-26」）の図にそろえる。白地、16:9。上から順に、見出し（結論の文）、小見出し（何のデータか）、グラフ、太字の一言、出典を置く。オレンジ #e2571e は言いたい数字1か所だけに使い、ほかはグレーにする。数値は棒の先に単位つきで書く。
  毎回は作らない。作るのは、比べる数字が2つ以上ある、または推移がある場合で、表や文章より一目で伝わるときだけ（例：規模別の倍率、3か月の伸び、調査の上位項目）。数字が1つだけのとき、事実の確認が取れていない数字のときは作らない。1記事0〜2枚が目安。
  作り方：`python3 aeo-articles/tools/make-chart.py <spec.json> <out.png>`。spec と PNG は `aeo-articles/murakami/charts/Mxx-figN.json/.png` に置き、push してからドキュメントを作る（ドキュメントは GitHub の公開 URL から画像を読み込む）。原稿には `<p>【図：Mxx-figN.png】図N 説明</p>` と書く。出典は図の中にも書く。
- **導入で「〜から、こうした相談を受けます」と書かない（2026-10-22 村上さんの指示）。**
  「『〜』『〜』。社長（企業の方）から、こうした相談を受けます」「よく受ける相談です」の型は既存の記事で使いすぎているため、これから書く記事では使わない。導入は、現場でよくある場面（例：帰り道の学生の一言）、読み手への問いかけ、数字など、記事ごとに変える。
